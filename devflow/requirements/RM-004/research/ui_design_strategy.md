## 色彩 / 字体 / 布局假设

### 色彩系统

**主色 (Primary)**:

- 用途: 主要操作按钮、链接、选中状态

**辅助色 (Secondary)**:

- 警告: `#E6A23C` (橙色)
- 危险: `#F56C6C` (红色)
- 信息: `#909399` (灰色)

**中性色 (Neutral)**:
- 主文本: `#303133` (深灰)
- 常规文本: `#606266` (中灰)
- 次要文本: `#909399` (浅灰)
- 占位文本: `#C0C4CC` (淡灰)
- 边框: `#DCDFE6` (浅边框)
- 背景: `#F2F6FC` (浅背景)

**对比度要求**:
- 正文文字与背景对比度 ≥ 4.5:1（WCAG AA标准）
- 大号文字（≥18pt）与背景对比度 ≥ 3:1

### 字体系统

**字体栈**:
```css

             "Helvetica Neue", Arial, "PingFang SC", "Hiragino Sans GB",
             "Microsoft YaHei", 微软雅黑, sans-serif;
```

**字阶 (Type Scale)**:
- **一级标题**: 20px / 1.5 / 500 (页面标题)
- **二级标题**: 18px / 1.5 / 500 (区块标题)
- **三级标题**: 16px / 1.5 / 500 (卡片标题)
- **正文**: 14px / 1.5 / 400 (主要内容)
- **辅助文字**: 13px / 1.5 / 400 (说明文字)
- **小号文字**: 12px / 1.5 / 400 (次要信息)

### 布局系统

**栅格系统**: 24列栅格（Element Plus标准）

**断点策略** (桌面端为主):
- `≥1920px`: 大屏幕（4K显示器）
- `1440px - 1919px`: 标准桌面
- `1024px - 1439px`: 小屏桌面/笔记本
- `<1024px`: 平板（降级体验，提示使用桌面端）

**间距系统** (基于8px网格):
- `4px`: 最小间距（图标与文字）
- `8px`: 小间距（表单项内部）
- `12px`: 常规间距（卡片内边距）
- `16px`: 标准间距（区块间距）
- `24px`: 大间距（页面区块）
- `32px`: 特大间距（页面边距）

**核心布局结构**:
```
┌─────────────────────────────────────────────────┐
│  Header (60px)                                   │  顶部导航栏
├──────┬──────────────────────────────────────────┤
│      │                                           │
│ Side │  Main Content Area                       │  主内容区
│ bar  │  (动态高度)                               │
│      │                                           │
│(200px│                                           │
│ 可折叠)│                                           │
└──────┴──────────────────────────────────────────┘
```

**布局规则**:
- 侧边栏宽度: 200px（展开）/ 64px（折叠）
- 顶部导航高度: 60px（固定）
- 内容区最大宽度: 1440px（居中显示）
- 内容区内边距: 20px（上下左右）

## 交互与响应式要点

### 核心交互模式

**1. 导航交互**:
- 侧边栏菜单支持折叠/展开（动画时间300ms）
- 当前路由高亮显示（背景色变化 + 左边框强调）
- 面包屑导航显示当前位置（点击可快速跳转）

**2. 表单交互**:
- 实时校验（失焦时触发）
- 错误提示显示在输入框下方（红色文字 + 图标）
- 提交按钮在未填写完整时禁用（防止误操作）

**3. 表格交互**:
- 支持分页（默认每页20条）
- 支持排序（点击表头图标）
- 行hover效果（背景色变化）
- 操作按钮（编辑、删除）hover时显示tooltip

**4. 反馈机制**:
- 成功操作: Message提示（绿色，自动关闭）
- 失败操作: Message提示（红色，手动关闭）
- 危险操作: MessageBox二次确认（删除、重置等）
- 加载状态: Loading遮罩（全屏或局部）

### 响应式断点策略

**主要断点** (基于Element Plus):
- `xs`: <768px（不支持，提示切换桌面端）
- `sm`: 768px - 991px（降级布局，隐藏部分次要功能）
- `md`: 992px - 1199px（标准布局）
- `lg`: 1200px - 1919px（标准布局）
- `xl`: ≥1920px（宽屏优化布局）

**响应式规则**:
1. **<1024px**: 侧边栏默认折叠，主内容区占满屏幕
2. **≥1024px**: 侧边栏默认展开，主内容区居中（max-width: 1440px）
3. **≥1920px**: 内容区可扩展至1600px（充分利用大屏空间）

### 可访问性 (Accessibility)

**基本要求**:
- 所有交互元素支持键盘操作（Tab、Enter、Esc）
- 表单输入框提供清晰的label标签
- 错误提示通过颜色+图标+文字三重传达（照顾色盲用户）
- 按钮提供明确的文字说明（避免仅使用图标）

**ARIA支持**:
- 动态内容更新时使用`aria-live`通知
- 模态框打开时焦点自动移入，关闭时焦点返回触发元素
- 禁用元素添加`aria-disabled="true"`属性
